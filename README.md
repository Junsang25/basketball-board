# 농구 전술판

선수와 공의 움직임을 코트 위에 그리고, 장면 단위로 재생·설명·내보내기 하는 웹 전술판.

**→ https://junsang25.github.io/basketball-board/**

설치할 것 없이 브라우저로 바로 열면 된다. 폰에서도 그대로 되고, **홈 화면에 추가하면 앱처럼 열리고 인터넷 없이도 돌아간다** (아래 [앱으로 설치](#앱으로-설치) 참고). 전술은 그 기기의 브라우저에 저장된다.

## 만들 때 정한 것

- **웹 앱** — PC(마우스)와 폰(터치)을 한 코드로 커버. 브라우저만 있으면 됨.
- **장면(스텝) 단위 애니메이션** — 실시간 손 떨림 녹화가 아니라, 장면마다 말을 놓으면 사이를 자동으로 부드럽게 이어 재생.
- **기능을 늘리지 않는다** — 시중 제품이 아쉬웠던 이유가 조잡함 아니면 기능 과잉이라서. 농구 전술을 그리는 데 꼭 필요한 것만 둔다.

## 실행

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 http://localhost:5173 접속.

배포용 빌드:

```bash
npm run build
```

`dist/` 폴더만 어디든 올리면 됨 (서버 불필요, 정적 파일).

## 배포

`main`에 push하면 [워크플로](.github/workflows/deploy.yml)가 빌드해서 GitHub Pages에 올린다. 따로 할 일은 없다.

`vite.config.ts`의 `base`가 `'./'`라서 경로가 전부 상대 경로로 뽑힌다. 그래서 저장소 이름이 바뀌든 다른 폴더에 올리든 그대로 열린다.

## 앱으로 설치

설치형 웹앱(PWA)이라 스토어를 거치지 않고 홈 화면에 올릴 수 있다. 아이콘이 생기고, 주소창 없이 전체화면으로 열리고, **한 번 열어본 뒤에는 인터넷이 끊겨도 돌아간다.** 체육관에서 신호 안 잡혀도 쓰라고 넣었다.

| 기기 | 방법 |
| --- | --- |
| 안드로이드 (크롬) | 주소창 옆 설치 아이콘, 또는 ⋮ → `앱 설치` |
| 아이폰 (사파리) | 공유 → `홈 화면에 추가` |
| PC (크롬·엣지) | 주소창 오른쪽 설치 아이콘 |

> **아이폰은 저장소가 분리된다.** 홈 화면 앱과 사파리는 서로 다른 저장 공간을 쓴다. 사파리에서 만들어둔 전술이 설치한 앱에선 안 보인다. 설치 전에 메뉴의 `내 전술` → `전체 백업 파일로 저장`을 해두고, 설치한 앱에서 불러오면 그대로 옮겨진다.

새로 배포된 게 있으면 앱을 열 때 알아서 최신으로 바뀐다. HTML은 항상 서버를 먼저 보고(끊겼을 때만 캐시), 나머지 파일은 이름에 해시가 붙어 있어서 오래된 걸 잘못 쓸 일이 없다.

아이콘은 `public/favicon.svg`가 원본이고, 설치용 PNG는 `pwsh tools/make-icons.ps1`로 다시 뽑는다.

## 분기 (갈래)

실제 전술은 거의 다 "읽기"다. 수비가 어떻게 나오느냐에 따라 다음 동작이 갈린다. 그래서 한 전술 안에 **갈래**를 여러 개 둘 수 있다.

메뉴 `장면`의 `＋ N번 장면에서 분기`를 누르면, 그 장면까지를 공유하고 거기서부터 갈라지는 새 갈래가 생긴다. 갈래 안에서 또 갈라지는 것도 된다 (깊이 제한 없음).

```
본선 ──────── 헤지 → 포켓 패스 → 마무리
   └ 드롭이면 ── 풀업 3점
   └ 스위치하면 ─ 미스매치 포스트업
        └ 더블팀 오면 ── 코너로 킥아웃
```

- 갈래 칩을 누르면 그 갈래로 이동한다. 지금 보고 있는 칩을 한 번 더 누르면 이름을 고칠 수 있다.
- 공유되는 앞 장면은 장면 칩이 **점선**으로 표시된다. 그 장면을 고치면 그 장면을 지나는 모든 갈래에 똑같이 반영된다 (같은 장면이니까).
- 공유 장면에서는 장면 추가·복제·삭제가 막힌다. 구조를 바꾸려면 그 장면을 소유한 갈래로 가면 된다.
- 갈래 칩의 `✕`로 지우면 그 아래 갈래도 함께 지워진다. `Ctrl+Z`로 되돌릴 수 있다.

**영상으로 내보내면 갈래가 하나로 이어진다.** 본선을 끝까지 보여준 뒤, 갈래마다 이름이 적힌 안내 화면이 나오고 분기점으로 되감아서 그 갈래를 재생한다. 코치 영상처럼 "기본은 이거고, 스위치하면 이렇게" 흐름이 한 파일에 담긴다. 화면 안에서 ▶로 재생할 때는 지금 보고 있는 갈래만 돈다.

## 샘플 전술

처음 켜면 **하이 픽앤롤**이 들어 있다. ▶를 누르면 바로 돌아간다.

본선 5장면:

1. 1-4 스프레드 — 코너를 벌려 도움수비를 묶는다
2. 5번이 올라와 스크린 (스크린 마커)
3. 1번은 스크린 타고 드리블 (물결선), 5번은 롤 (곡선 화살표)
4. 포켓 패스 (점선)
5. 마무리 (림으로 가는 점선)

3번 장면에서 `드롭이면` / `스위치하면` 두 갈래가 갈라지고, `스위치하면` 안에서 다시 `더블팀 오면`이 갈라진다. 전술 표기 다섯 가지와 분기 구조가 한 번씩 다 나오니까, 어떻게 만드는지 감 잡는 용으로 보면 된다.

지웠거나 이미 쓰던 전술이 있어서 안 보이면 `내 전술` 아래의 `픽앤롤 샘플 전술 가져오기`로 언제든 다시 꺼낼 수 있다.

## 쓰는 법

| 하고 싶은 것 | 조작 |
| --- | --- |
| 말 배치 | 코트 위에서 드래그 |
| 말 놓기 | 메뉴의 `공격` / `수비` / `콘` → 메뉴가 닫히면 코트의 놓고 싶은 자리를 터치 |
| 공 | 다른 말처럼 그냥 끌어서 옮긴다 (누구 것도 아니다) |
| 다음 장면 만들기 | 메뉴 `장면`의 `+` |
| 움직임 만들기 | 새 장면에서 말을 옮기면 끝. 화살표는 자동 |
| 곡선으로 휘기 | 말을 고른 뒤 화살표 가운데 점을 드래그 |
| 표기 바꾸기 / 삭제 | 말을 누르면 뜨는 막대의 `이동` / `드리블` / `삭제` |
| 스크린 놓기 | 메뉴의 `스크린` → 코트를 터치해서 놓고, 위아래로 움직여 각도를 맞춘 뒤 손을 뗀다 |
| 장면 설명 | 메뉴 `장면`의 입력칸 |
| 재생 | 메뉴 `장면`의 ▶ (스페이스바). 재생 중엔 구석 버튼이 `■`로 바뀐다 |
| 코트 디자인·말 크기·편집 창 | 메뉴의 `설정` |
| 전체화면 | 메뉴의 `전체화면` |

키보드: `Space` 재생, `←` `→` 장면 이동, `Ctrl+Z` 되돌리기, `Delete` 선택한 말 삭제, `Esc` 선택 해제 / 메뉴 닫기.

## 화면 구성

**코트가 화면 전체다.** 조작부는 구석의 버튼 하나(`☰`)뿐이고, 장면이 둘 이상이면 버튼에 `2/5`처럼 지금 장면이 같이 보인다.

버튼을 누르면 **코트와 따로 노는 메뉴 화면**으로 넘어간다. 코트 위에 떠 있는 창이 아니라서 아무것도 가리지 않는다.

- **말 놓기** — 공격 / 수비 / 콘 / 스크린
- **장면** — 갈래, 재생, 장면 목록, 장면 설명, 이동 속도
- **코트** — 하프/풀코트, 가로/세로, 되돌리기, 전체화면
- **전술** — 내 전술, 내보내기, 설정

`공격` `수비` `콘` `스크린`을 누르면 메뉴가 닫히고 코트로 돌아간다. 그다음 코트를 터치하면 **그 자리에** 말이 놓인다. 놓는 동안 구석 버튼은 `✕`로 바뀌어서, 누르면 놓기를 그만둔다 (스크린은 여러 개 놓을 수 있어서 `✕`를 누를 때까지 계속 놓인다). `▶`로 재생을 시작해도 메뉴가 닫히고, 구석 버튼이 `■`가 되어 멈출 수 있다.

### 말을 눌렀을 때

말을 누르면 작은 막대가 뜬다. 기능은 셋뿐이다.

| 버튼 | 언제 |
| --- | --- |
| `이동` / `드리블` | 이번 장면에서 움직인 선수일 때만 |
| `삭제` | 늘 (공은 지울 수 없어서 막대 자체가 안 뜬다) |

막대는 **눌러 둔 말을 가리지 않도록** 말이 있는 쪽의 반대편 가장자리(말이 아래쪽이면 위, 위쪽이면 아래)에 붙는다.

설정의 `말 편집 창`을 `간략`으로 바꾸면 글자 없이 아이콘(`→` `≈` `✕`)만 남고 구석 버튼도 작아진다. 폰처럼 좁은 화면에서 쓰라고 만든 모드다. 기기마다 따로 저장된다.

`전체화면`을 누르면 브라우저 전체화면에 들어간다. 지원하지 않는 브라우저(iOS 사파리 등)에서는 조용히 넘어간다. 홈 화면에 설치해서 쓰면 주소창이 애초에 없다.

## 보기 설정

메뉴의 `설정`에서 **코트 디자인**, **말 크기**, **말 편집 창**(보통/간략)을 바꾼다. 설정을 여는 동안은 메뉴가 접혀서 코트를 보면서 고를 수 있다.

| 디자인 | 어떤 느낌 |
| --- | --- |
| `마루` | 체육관 바닥. 차분한 나무색에 흐린 갈색 선 |
| `칠판` | 코치 보드. 짙은 녹색 바탕에 분필색 선, 흰 공격 말 |
| `종이` | 전술 노트. 흰 바탕에 가는 회색 선, 테두리만 있는 말 |
| `야간` | 어두운 화면. 앱 색과 같은 계열 |

말 크기는 `작게 / 보통 / 크게 / 아주 크게` 네 단계다. 코트 대비 비율이라 화면을 키워도 그대로다. 선수가 많으면 작게, 멀리서 보여줄 땐 크게 쓰면 된다. 번호 글씨와 테두리 두께도 같이 따라간다.

**화면에 보이는 그대로 PNG와 영상에도 들어간다.** 코트·말·움직임 선을 한 벌의 색으로 모아놨고(`src/lib/look.ts`), 화면과 내보내기가 같은 그리기 코드를 쓰기 때문이다.

설정은 전술이 아니라 기기에 저장된다. 전술 파일을 다른 기기로 옮겨도 그 기기에서 고른 디자인으로 보인다.

## 움직임 표기

농구 다이어그램 표준을 따른다.

- **실선 + 화살표** — 선수 이동 (컷)
- **물결선 + 화살표** — 드리블
- **점선 + 화살표** — 패스 / 슛
- **굵은 막대** — 스크린 (직접 놓는다, 아래 참고)

이동 표기는 자동으로 결정된다. 선수가 움직이면 컷, 공이 움직이면 패스선. 필요하면 선수를 골라 이동/드리블을 직접 바꿀 수 있다. (공은 소유권이 없는 하나의 말이다. 예전에 만든 전술 중 공을 선수에게 붙여둔 것은 그대로 따라다니고, 공을 직접 끌면 떨어진다.)

### 스크린

스크린은 자동으로 판정하지 않는다. **직접 놓는 마커**다. 벽처럼 생긴 굵은 막대 하나.

메뉴의 `스크린`을 누르면 설치 모드가 된다. 놓는 것과 각도를 맞추는 것이 한 동작으로 이어진다.

**마우스**

| 조작 | 결과 |
| --- | --- |
| 클릭 | 그 자리에 막대가 바로 생기고, 각도 맞추기가 시작된다 |
| (버튼 떼고) 위아래로 움직이기 | 움직인 만큼 돈다. 위로 올리면 반시계, 130px에 반 바퀴. 좌우 움직임은 무시 |
| 다시 클릭 | 그 각도로 확정 |
| 각도 맞추는 중 우클릭 | 방금 놓은 막대를 버린다 |
| 이미 놓은 막대를 클릭 | 각도를 다시 맞춘다 (끌면 위치 옮기기) |
| 이미 놓은 막대에 우클릭 | 삭제 |
| 막대를 코트 밖으로 끌어내기 | 삭제 |
| `Esc` | 설치 모드 끝내기 (맞추던 각도 그대로 남는다) |

**터치**

| 조작 | 결과 |
| --- | --- |
| 손을 대면 | 그 자리에 막대가 생긴다 |
| 떼지 않고 위아래로 끌기 | 움직인 만큼 돈다 |
| 손을 떼면 | 확정 |
| 이미 놓은 막대를 끌기 | 위치 옮기기 |
| 코트 밖으로 끌어내고 떼기 | 삭제 (폰에는 우클릭이 없으니 이게 지우는 방법) |

막대를 코트 밖으로 끌어내면 빨간 점선으로 바뀐다. 그 상태에서 손을 떼면 사라지고, 코트 안으로 다시 들여놓으면 없던 일이 된다. 실수로 버렸으면 `Ctrl+Z` 한 번에 원래 자리로 돌아온다 (끌고 나간 자취까지 같이 되돌아간다).

- 막대는 **놓은 그 장면에만** 있다. 다음 장면으로 넘어가면 사라진다. 장면을 새로 추가해도 따라오지 않는다.
- 재생하면 **그 장면의 움직임이 끝날 때쯤** 떠오른다. 선수들이 이동하는 동안에는 안 보인다.
- 한 장면에 여러 개 놓아도 된다.

**패스선**: 공을 옮기면 "그 장면의 시작 위치에서 도착 위치까지" 선이 그려진다. `움직인 다음 패스`를 그리고 싶으면 장면을 둘로 나누면 된다.

## 저장과 내보내기

- 전술은 **브라우저에 자동 저장**된다 (localStorage). 새로고침해도 남아 있음.
- 메뉴의 `내 전술`에서 여러 전술을 만들고 오갈 수 있다.
- `내보내기` 메뉴:
  - **PNG** — 현재 장면 한 장 (설명이 아래 캡션으로 들어감)
  - **MP4** — 전체 움직임 영상. 장면마다 잠깐 멈춰서 설명을 읽을 시간을 준다. MP4를 지원하지 않는 브라우저에서는 WebM으로 저장됨
  - **전술 파일 (.json)** — 다른 기기로 옮기거나 백업할 때

> 기기를 바꾸면 브라우저 저장소는 따라가지 않는다. 옮길 땐 전술 목록 아래의 `전체 백업 파일로 저장`을 쓸 것.

## 코드 구조

```
src/
  lib/
    types.ts       데이터 모델 (Play / Step / Token)
    geom.ts        벡터, 곡선(Catmull-Rom), 폴리라인 유틸
    court.ts       NBA 규격 코트 치수 + 코트 그리기 + 좌표 변환
    play.ts        전술 조작 (말 추가/삭제, 스텝 조작, 표기 자동 판정)
    frame.ts       특정 시점의 화면 상태 계산 (보간 + 움직임 선)
    timeline.ts    재생 타임라인 (이동 구간 + 멈춤 구간)
    render.ts      캔버스에 말과 움직임 기호 그리기
    storage.ts     localStorage 저장, 파일 내보내기/불러오기
    exportMedia.ts PNG / 영상 내보내기
    pwa.ts         서비스워커 등록 (설치 / 오프라인)
    look.ts        코트 디자인(테마)과 말 크기 — 색은 전부 여기
    uiState.ts     보기 설정 저장 (전술 데이터와 따로)
  ui/
    Board.tsx      캔버스 + 포인터 조작
    MenuScreen.tsx 메뉴 화면 (말 놓기, 코트, 전술)
    StepBar.tsx    장면 타임라인 + 설명 (메뉴 안)
    Inspector.tsx  말을 눌렀을 때 뜨는 막대 (이동/드리블/삭제)
    PlaybookPanel.tsx  전술 목록
    SettingsPanel.tsx  보기 설정
  App.tsx          상태 관리
public/
  manifest.webmanifest  설치 정보 (이름, 아이콘, 전체화면)
  sw.js                 서비스워커 (오프라인 캐시)
  favicon.svg           아이콘 원본
```

좌표계는 **피트 단위**다. `x: -25~25` (코트 폭 50ft), `y: 0~47 또는 0~94` (0이 공격 베이스라인). 화면·PNG·영상이 전부 같은 렌더링 코드를 쓰기 때문에, 보이는 그대로 저장된다.
